# Soumyadip Samanta — Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — layout, typography, responsive styling and visual effects
- `script.js` — project carousel, modal interactions and keyboard/touch controls

## Preview locally
Keep all three files in the same folder, then open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload all three files to the root of your existing portfolio repository.
2. Commit the changes.
3. Ensure GitHub Pages is configured to deploy from the correct branch and root folder.
4. Visit https://5oumyadip.github.io/.

## Before publishing
- Add verified repository/live-demo links for each project.
- Add actual certificate verification links if desired.
- Add your professional email and LinkedIn URL if you want those contact methods displayed.
- Confirm that the project descriptions, skills and education details are accurate.
